Install Amendment Layers

Amendment Layers is a Microsoft Word add-in for displaying pending amendments during meetings. Word on each computer needs the add-in’s file, manifest.xml.

Download manifest.xml
  1. Click Download manifest.xml above. It is saved to your Downloads folder.
  2. Follow section 11, Installing on a computer, of the Amendment Layers — User Manual: put the file in a shared folder, add that folder to Word’s Trusted Add-in Catalogs, and add the add-in.

No account is needed. Word loads the rest of the add-in from this website each time it opens.
